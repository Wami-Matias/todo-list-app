# 📝 To-Do List Application

Uma aplicação de lista de tarefas simples e elegante com armazenamento local.

## Funcionalidades

✅ **Adicionar Tarefas** — Pressiona Enter ou clica no botão "Adicionar"  
✅ **Marcar como Concluída** — Clica no checkbox para marcar/desmarcar  
✅ **Apagar Tarefas** — Remove tarefas individuais com confirmação  
✅ **Filtros** — Visualiza Todas, Ativas ou Completas  
✅ **Persistência com Local Storage** — As tarefas são salvas automaticamente  
✅ **Estatísticas** — Conta de tarefas totais e completas  
✅ **Design Responsivo** — Funciona perfeitamente em desktop e mobile  
✅ **Animações Suaves** — Transições e efeitos elegantes  

## Como Usar

1. Clona ou faz download do repositório
2. Abre `index.html` no navegador
3. Começa a adicionar tarefas!

- HTML5

## Exemplo de Uso

1. **Adicionar Tarefa**: Escreve a tarefa e clica "Adicionar" ou pressiona Enter
2. **Marcar Concluída**: Clica no checkbox ao lado da tarefa
3. **Filtrar**: Clica em "Todas", "Ativas" ou "Completas"
4. **Apagar**: Clica no botão "Apagar" na tarefa
5. **Limpar Completas**: Clica em "Limpar completas" para remover todas as completas

## Data Persistência

Todas as tarefas são guardadas automaticamente no `localStorage` do navegador. Isto significa que:

- As tarefas persistem após fechar o navegador
- Funcionam offline
- Não requerem servidor
